## What this means for Apprentice Guide

1. **Add short looping Reels (6–16s).** Our Reels run 21–43s with voiceover. The biggest faceless outliers in our niche are one dense screen that loops. Cheap to make with the engine.
2. **Lists sorted low → high, all on screen at once,** two-column grid (trade | pay).
3. **Case-study Reel uses the year-card structure:** year top, short caption bottom, speed up over time, one honest setback, end on a one-liner with no year.
4. **Every Reel ends with a comment prompt** ("Which trade would you pick?", "Tag the mate buying a ute").
5. Face-to-camera still dominates the top of the niche. Optional later if Joseph wants to be on camera.
